Random Submission Drawer

Hit the button to draw a random jam submission from the jar. Each drawn submission is removed from the jar, so you won't get the same one twice.

Heads up: your draws are saved in this browser, so refreshing the page won't empty the jar or your drawn list. Use the reset button to start over.
