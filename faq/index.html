Indubitably.

How can I contact the organizers?

In case of very important organization issues, use this email:

skgjam@tuta.com

https://discord.gg/cB5ARNyDfA

How can I help the jam?

Just as the movement itself, the jam has been created by the community for the community.

So please, support us by spreading the word!

Also, we need volunteers to create or suggest any helpful materials for the jam participants. If you know any resources/tutorials/articles that would make it easier making a game jam entry - let us know on the discord. Especially we need help describing how to prepare Web builds for the popular langs and framework.

Don't hesitate to contact discord user PotatoGameDev, he is responsible for the page!

If you want to influence this page itself, add some articles, fix typos, help with the styles - check out the github repo: github.com/PotatoGameDev/skgjam-page

Feel free to create a pull request!
